Roteiro de estudos para quem quer começar a aprender sobre tecnologia

  1. Introdução à Web
    1. Aprender sobre o que é web, e a diferença entre web e internet.
  2. Estrutura da Web
    1. Compreender a estrutura da web, como funcionam as requisições e protocolos.
  3. Estrutura de um projeto Web
    1. Compreender as principais "partes" de um projeto Web (HTML,CSS, javaScript...) e suas respectivas funções.

Depois que aprendermos as principais "partes" de um projeto Web, veremos cada uma mais detalhadamente, a começar por HTML

  1. Fundamentos do HTML
    1. Compreender o que é HTML, sua estrutura e principais tags
  2. HTML Semântico
    1. Compreender o que é semântica, sua importância e principais elementos
  3. Tabelas, Listas e Mídia
    1. Compreender o que são e como usar os elementos de tabela, lista e mídia em um documento HTML

Ranking de Tecnologias

  1. Git / Github

    Permite que desenvolvedores acompanhem mudanças no código, revertam erros, criem ramificações (branches) e colaborem em projetos de forma segura e eficiente.

  2. VSCode

    O editor de código mais popular do mercado, utilizado para escrever, organizar e testar projetos de software com eficiência.

  3. HTML5

    Linguagem de marcação com o propósito de descrever a estrutura e o significado do conteúdo de um documento hipermídia.

  4. CSS3

    Tecnologia utilizada para estilizar as páginas, controlando cores, fontes, layouts e a responsividade do site.

  5. JavaScript

    Linguagem de programação essencial para criar interatividade, animações e lógica no lado do cliente (front-end).

Glossário de Termos Técnicos

Frontend
Client-side
Camada de desenvolvimento responsável pela interface com a qual o usuário interage diretamente no navegador.
Backend
Server-side
Camada de desenvolvimento responsável pela lógica de negócios, processamento de dados e comunicação com o banco de dados, que roda diretamente no servidor e nos bastidores da aplicação
IP(Internet Protocol)
O protocolo/regra de rede que cuida de como os dados são formatados e transmitidos pela internet.
O endereço numérico único (ex: 192.168.0.1) que identifica cada dispositivo conectado à rede.
Server(Servidor)
A máquina/computador físico de alta potência que fica ligado 24 horas por dia guardando os arquivos do site(hardware).
O programa de sistema (como Apache ou Nginx) que roda nessa máquina e é responsável por processar e responder às requisições do navegador(software).
HTTP
O protocolo de transferência que permite a troca de informações e arquivos entre o cliente (navegador) e o servidor.
DNS
O sistema que traduz nomes de domínios amigáveis (como google.com) para os endereços de IP reais dos servidores.
